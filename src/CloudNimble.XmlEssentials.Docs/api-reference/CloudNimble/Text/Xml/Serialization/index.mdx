## Summary

`CloudNimble.Text.Xml.Serialization` holds the types that shape how [`XmlSerializer`](/api-reference/CloudNimble/Text/Xml/XmlSerializer) maps .NET objects to XML: the attributes you put on your types, the enumerations that the options use, the base classes for custom converters, and the support types for source generation.

| To do this | Use |
| --- | --- |
| Name the document element | [`XmlRootAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlRootAttribute) |
| Rename a member | [`XmlPropertyNameAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlPropertyNameAttribute) |
| Write a member as an element, an XML attribute, or element text | [`XmlElementAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlElementAttribute), [`XmlAttributeAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlAttributeAttribute), [`XmlTextAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlTextAttribute) |
| Set the order of members | [`XmlPropertyOrderAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlPropertyOrderAttribute) |
| Leave a member out | [`XmlIgnoreAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlIgnoreAttribute) |
| Require a member when reading | [`XmlRequiredAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlRequiredAttribute) |
| Choose the constructor used when reading | [`XmlConstructorAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlConstructorAttribute) |
| Wrap a collection and name its items | [`XmlArrayAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlArrayAttribute), [`XmlArrayItemAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlArrayItemAttribute) |
| Serialize derived types | [`XmlPolymorphicAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlPolymorphicAttribute), [`XmlDerivedTypeAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlDerivedTypeAttribute) |
| Write your own conversion for a type | [`XmlConverter`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlConverter) |
| Generate serialization code at compile time | [`XmlSerializerContext`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlSerializerContext), [`XmlSerializableAttribute`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlSerializableAttribute) |

## Usage

Import the namespace next to `CloudNimble.Text.Xml`, then annotate your types:

```csharp
using CloudNimble.Text.Xml;
using CloudNimble.Text.Xml.Serialization;
```

```csharp
[XmlRoot("product")]
public sealed class CatalogItem
{
    [XmlAttribute("sku")]
    public string? Sku { get; set; }

    [XmlPropertyName("title")]
    public string? Name { get; set; }

    [XmlElement("unit-price")]
    public decimal UnitPrice { get; set; }
}
```

```csharp
var item = new CatalogItem { Sku = "KB-101", Name = "Keyboard", UnitPrice = 49.95m };
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };

string xml = XmlSerializer.Serialize(item, options);
output.WriteLine(xml);

CatalogItem? copy = XmlSerializer.Deserialize<CatalogItem>(xml, options);
output.WriteLine($"{copy!.Sku}: {copy.Name}");
```

The code produces the following output:

```text
<product sku="KB-101"><title>Keyboard</title><unit-price>49.95</unit-price></product>
KB-101: Keyboard
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/08_CustomizeNames.cs)

The how-to guides cover each group of attributes: [Customize names and shape](/guides/customize-names), [Ignore properties](/guides/ignore-properties), [Require properties](/guides/required-properties), [Immutable types](/guides/immutable-types), and [Serialize collections](/guides/collections).

## Considerations

- **These aren't the `System.Xml.Serialization` attributes.** Several types here have the same names as attributes in `System.Xml.Serialization`, such as `XmlRootAttribute`, `XmlElementAttribute`, `XmlAttributeAttribute`, and `XmlIgnoreAttribute`. The serializer reads only the ones in this namespace. An attribute from `System.Xml.Serialization` on your type is ignored.
- **Don't import both namespaces in one file.** `[XmlElement]` would be ambiguous and the file wouldn't compile. When you move a type over, replace `using System.Xml.Serialization;` with `using CloudNimble.Text.Xml.Serialization;`. See [Migrate from XmlSerializer](/guides/migrate/from-xmlserializer).
- **The same names don't always mean the same defaults.** For example, a collection has no wrapper element here unless you add `[XmlArray]` or set `DefaultCollectionMapping` to `Wrapped`. `XmlSerializerOptions.Bcl` sets the defaults that write what `System.Xml.Serialization.XmlSerializer` writes.
- **Mapping mistakes are reported on first use.** A combination that can't be mapped, such as `[XmlAttribute]` on an object member or `[XmlText]` on a type that also has child elements, throws a `NotSupportedException` the first time the type is serialized or deserialized.
