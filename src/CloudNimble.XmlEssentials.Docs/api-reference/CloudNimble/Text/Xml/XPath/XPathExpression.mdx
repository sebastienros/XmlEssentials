## Summary

A compiled XPath 1.0 expression, which can be evaluated over any number of [XmlDocument](/api-reference/CloudNimble/Text/Xml/XmlDocument)
instances.

## Remarks

An expression is immutable, and may be evaluated from several threads at once, over one document or many. It
holds its names and literals as UTF-8 and compares them with the rows of the document byte for byte, so an
evaluation transcodes nothing until it returns its result.

## Examples

```csharp
var expensive = XPathExpression.Compile("/catalog/item[price > 10]/@id");
using var document = XmlDocument.Parse(catalog);
foreach (var id in expensive.Select(document))
{
    Console.WriteLine(id.GetString());
}
```

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Compile

Compiles an XPath 1.0 expression.

#### Syntax

```csharp
public static CloudNimble.Text.Xml.XPath.XPathExpression Compile(string expression, CloudNimble.Text.Xml.XPath.XPathOptions options = null)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `expression` | `string` | The expression. |
| `options` | `CloudNimble.Text.Xml.XPath.XPathOptions?` | The prefixes the expression may use and the limits on it, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for none and the defaults. |

#### Returns

Type: `CloudNimble.Text.Xml.XPath.XPathExpression`
The compiled expression.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentException` | *expression* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), empty or white space.
-or-
[XPathOptions.Namespaces](/api-reference/CloudNimble/Text/Xml/XPath/XPathOptions#namespaces) binds `xml` to another namespace, binds `xmlns`, or binds a
prefix to an empty namespace URI. |
| `XPathException` | The expression is not an XPath 1.0 expression; it uses a prefix that [XPathOptions.Namespaces](/api-reference/CloudNimble/Text/Xml/XPath/XPathOptions#namespaces)
does not bind, a function that is not a core function, or a function with the wrong number of arguments; or
it is nested deeper than [XPathOptions.MaxDepth](/api-reference/CloudNimble/Text/Xml/XPath/XPathOptions#maxdepth). [XPathException.Position](/api-reference/CloudNimble/Text/Xml/XPath/XPathException#position) says
where. |

#### Examples

```csharp
var options = new XPathOptions { Namespaces = new Dictionary<string, string> { ["a"] = "http://www.w3.org/2005/Atom" } };
var titles = XPathExpression.Compile("//a:entry/a:title", options);
```

#### Remarks

The whole expression is checked for syntax before its names are checked, so a syntax error anywhere is the
error reported. A variable is not checked until the expression is evaluated.
