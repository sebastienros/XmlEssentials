## Summary

Specifies the kind of a node in the XPath 1.0 data model.

## Remarks

The seven kinds are those of the XPath 1.0 Recommendation, section 5. A text node is a run of adjacent text
and CDATA sections that holds at least one character. A namespace node stands for one prefix in scope on an
element; the document holds no row for it.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Document` | 0 | The document node, which is the parent of the document element. |
| `Element` | 1 | An element. |
| `Attribute` | 2 | An attribute that is not a namespace declaration. |
| `Namespace` | 3 | A prefix in scope on an element, and the namespace URI it is bound to. |
| `Text` | 4 | A run of adjacent text and CDATA sections that holds at least one character. |
| `Comment` | 5 | A comment. |
| `ProcessingInstruction` | 6 | A processing instruction. |
