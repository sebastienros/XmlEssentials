## Summary

A node of an [XmlDocument](/api-reference/CloudNimble/Text/Xml/XmlDocument) in the XPath 1.0 data model, as an XPath expression selects it.

## Remarks

A node is a cursor into its document, as [XmlElement](/api-reference/CloudNimble/Text/Xml/XmlElement) is: it is used before the document is
disposed, and using it afterwards throws [ObjectDisposedException](https://learn.microsoft.com/dotnet/api/system.objectdisposedexception). Two nodes are equal when they
are the same node of the same document. A default [XPathNode](/api-reference/CloudNimble/Text/Xml/XPath/XPathNode) refers to no node, and every member
of it throws [InvalidOperationException](https://learn.microsoft.com/dotnet/api/system.invalidoperationexception).

The document node and the namespace nodes have no row in the document, so they have no
[XmlElement](/api-reference/CloudNimble/Text/Xml/XmlElement). A text node is a run of adjacent text and CDATA sections, and its
[XmlElement](/api-reference/CloudNimble/Text/Xml/XmlElement) is on the first of them.

## Examples

```csharp
foreach (var node in XPathExpression.Compile("//@id").Select(document))
{
    Console.WriteLine($"{node.LocalName} = {node.GetString()}");
}
```
