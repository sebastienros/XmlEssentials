## Summary

The values of the variables an XPath expression refers to as `$name`.

## Remarks

A variable is named by its local name and its namespace URI. A prefix in the expression, as in
`$p:name`, is resolved with [XPathOptions.Namespaces](/api-reference/CloudNimble/Text/Xml/XPath/XPathOptions#namespaces) when the expression is compiled.

The same instance may be passed to any number of evaluations. It is not safe to set a value while an
evaluation that uses the instance runs on another thread.

## Examples

```csharp
var byId = XPathExpression.Compile("/feed/entry[@id = $id]/title");
var variables = new XPathVariables();
variables.Set("id", "urn:entry:7");
var title = byId.Evaluate(document, variables).GetString();
```


#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `localName` | `string` | The local name of the variable. |
| `value` | `CloudNimble.Text.Xml.XPath.XPathNodeSet` | The value: a node-set that an evaluation over the same document returned. |
| `namespaceUri` | `string` | The namespace URI of the variable, or empty for no namespace. |

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | *localName*, *value* or *namespaceUri* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |
| `ArgumentException` | *localName* is empty or white space. |

#### Remarks

The node-set can be used only in an evaluation over the document it came from. Using it in an evaluation
over another document throws [ArgumentException](https://learn.microsoft.com/dotnet/api/system.argumentexception) from that evaluation.
