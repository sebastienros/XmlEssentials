## Summary

The nodes an XPath expression selected, in document order and without duplicates.

## Remarks

A node-set holds its document and the ids of its nodes; each [XPathNode](/api-reference/CloudNimble/Text/Xml/XPath/XPathNode) is a cursor into the
document, used before it is disposed. `foreach` uses a struct enumerator, so it does not allocate. The
order of the namespace nodes of one element is the order of their declarations, with `xml` first, and
the order of the attributes of one element is the order of the start tag.

## Examples

```csharp
var items = XPathExpression.Compile("/catalog/item").Select(document);
for (var i = 0; i < items.Count; i++)
{
    var id = items[i].GetElement().GetAttribute("id").GetInt32();
}
```
