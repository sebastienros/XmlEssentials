## Summary

The value of an XPath expression: a node-set, a boolean, a number or a string.

## Remarks

[XPathResult.GetBoolean](/api-reference/CloudNimble/Text/Xml/XPath/XPathResult#getboolean), [XPathResult.GetNumber](/api-reference/CloudNimble/Text/Xml/XPath/XPathResult#getnumber) and [XPathResult.GetString](/api-reference/CloudNimble/Text/Xml/XPath/XPathResult#getstring) convert a result of any kind as the
          XPath functions `boolean()`, `number()` and `string()` do. A string result is made a
          [String](https://learn.microsoft.com/dotnet/api/system.string) before the evaluation returns. A node-set result holds its document, which must not be
          disposed before the nodes are used.

A default [XPathResult](/api-reference/CloudNimble/Text/Xml/XPath/XPathResult) is the result of no evaluation, and every member of it throws
[InvalidOperationException](https://learn.microsoft.com/dotnet/api/system.invalidoperationexception).

## Examples

```csharp
var total = XPathExpression.Compile("sum(/order/line/@amount)").Evaluate(document).GetNumber();
var open = XPathExpression.Compile("/order/@status = 'open'").Evaluate(document).GetBoolean();
```
